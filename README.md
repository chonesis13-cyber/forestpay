## 🍃 프로젝트 소개
**포레스트 페이**는 매일의 노력을 기록하고, 복잡한 수당 계산을 한눈에 확인하기 위해 만들어졌습니다.  
깊은 숲을 닮은 **Deep Forest** 인터페이스를 통해 눈의 피로를 덜고, 차분하게 한 달의 결실을 확인해 보세요.

## ✨ 주요 기능
* **일당 기반 실시간 계산**: 기본 일당 입력 시 근무일수에 따른 급여 즉시 산출
* **지능형 휴일 가산**: 토요일, 일요일 및 법정 공휴일 터치 시 **자동 1.5배 수당** 적용
* **인터랙티브 캘린더**: 날짜 터치만으로 출근 기록을 등록하고 수정하는 간편한 UI
* **데이터 로컬 저장**: 브라우저를 닫아도 설정한 일당과 기록이 유지되는 LocalStorage 활용
* **딥 포레스트 테마**: 심리적 안정감을 주는 고유의 그린 컬러 팔레트 적용
